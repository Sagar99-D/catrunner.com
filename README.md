# Cat Runner

An endless-runner browser game: run, jump over plants, and duck under birds.

## How to play
Open `index.html` in any modern browser (no install or server needed).

| Action | Keyboard | Touch |
|---|---|---|
| Jump / start / restart | Space or Up Arrow | Tap |
| Duck (fast-fall in air) | Down Arrow | Tap the bottom of the game |
| Mute | M | - |

Your high score is saved in the browser.

## Files
- `index.html` - page
- `style.css` - styling
- `game.js` - all game logic and drawing (cat is drawn in code, no images needed)
- `death.mp3` - sound played on GHEE GHATAM (replace it with any mp3 using the same name)
